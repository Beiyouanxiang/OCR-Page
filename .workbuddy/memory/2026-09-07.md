## 15:05 修复登录成功无法跳转

**问题**：登录接口返回成功并显示「登录成功」toast，但页面仍停留在登录界面。

**根因**：`.login-screen` 定义了 `display: grid`，HTML5 `[hidden]` 默认样式优先级不足以覆盖该 display 规则；调用 `loginScreen.hidden = true` 时，登录页仍然可见。

**修复**：在 `public/style.css` 全局添加：

```css
[hidden] {
  display: none !important;
}
```

**部署**：已推送到 GitHub 并 reload 服务器 PM2，外网 `http://120.25.150.103/ocr/style.css` 已包含该规则。

## 15:18 修复 Ctrl+V 粘贴图片「无法解析该图片文件」

**问题**：登录后按 Ctrl+V 粘贴截图，提示「无法解析该图片文件」。

**根因**：Windows 剪贴板中的截图有时是 `image/bmp`、`image/dib` 或没有文件扩展名的特殊格式；HTML `<img>` 元素无法直接解码这些格式，但浏览器的 `createImageBitmap` 通常可以。

**修复**：
1. `loadImageFromFile` 增加 fallback：`<img>` 解码失败时，用 `createImageBitmap` 读取，再绘制到 canvas 上转成 PNG，最后重新生成可识别的 Image。
2. `getImageFromClipboard` 增强来源：除了 `files`/`items`，还支持 `text/html` 中的网络图片 URL / blob URL、以及 `text/plain` 中的图片 URL。
3. `onPaste` 改为 `await` 异步解析。

**部署**：已 push 并服务器 PM2 reload，`app.js` 已包含 `createImageBitmap` fallback。
